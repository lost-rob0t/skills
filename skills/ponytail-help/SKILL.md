# Ponytail Help

> External import of **Ponytail** by Dietrich Gebert and contributors, adapted from upstream v4.9.0 under MIT.

## Goal

Show the Ponytail skill suite and mode controls installed by this skills repository.

## Output

Present this reference:

- `ponytail lite` — build what was asked; mention the lazier alternative.
- `ponytail` / `ponytail full` — enforce YAGNI → existing code → stdlib → native → installed dependency → one line → minimum code.
- `ponytail ultra` — deletion-first, aggressive YAGNI.
- `ponytail-review` — diff review for over-engineering.
- `ponytail-audit` — whole-repo over-engineering audit.
- `ponytail-debt` — collect `ponytail:` shortcut markers.
- `ponytail-gain` — show upstream benchmark scoreboard.
- `ponytail-help` — this reference.

Once Ponytail is active, its selected level persists for the session. Say `stop ponytail` or `normal mode` to deactivate.

## Rules

This repository deploys canonical skills through its own adapters. Do not copy Ponytail's upstream `.claude`, `.opencode`, `.codex`, or other generated/provider-specific trees into the target repository merely to use these skills.
